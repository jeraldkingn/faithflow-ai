# faithflow-ai

Video generation requires FFmpeg. Install it and add `ffmpeg.exe` to `PATH`, or set
`FFMPEG_PATH` to the full path of the executable before running the application.

Shorts images belong in `images/b.hook`, `images/b.emotion`, `images/b.struggle`,
`images/b.message`, and `images/e.ending`, in scene order.

Background audio files belong in `audio/bg_shorts.mp3` and `audio/bg_long.mp3`.
